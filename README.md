Praxisverwaltungssystem

Eine Desktop-Anwendung zur digitalen Verwaltung einer medizinischen Praxis. Das Projekt wurde mit Java und JavaFX entwickelt.

Funktionen

Anmeldung über eine Login-Oberfläche

Verwaltung von Ärzten

Verwaltung von Patienten

Verwaltung von Behandlungseinträgen

Verwaltung von Terminen

PDF-Erstellung für Patienten- und Arztdaten

Benutzeroberfläche mit CSS-Styling

Strukturierter Aufbau mit DAO-, Service-, Model- und View-Paketen

Verwendete Technologien

Java 21

JavaFX 21

JDBC

MySQL

CSS

OpenPDF 1.3.39

IntelliJ IDEA / WebStorm

Projektstruktur

src/
└── de/praxis/
├── css/
├── dao/
├── fonts/
├── images/
├── model/
├── service/
└── view/

Architektur

View: Benutzeroberfläche und Darstellung

Model: Datenmodelle für Ärzte, Patienten, Behandlungen und Termine

DAO: Datenbankzugriff

Service: Anwendungslogik und PDF-Erstellung

Ziel des Projekts

Das Ziel ist es, typische Verwaltungsaufgaben einer medizinischen Praxis in einer übersichtlichen Desktop-Anwendung zu bündeln und die Kenntnisse in Java, JavaFX und Datenbankanbindung praktisch anzuwenden.

Hinweis

Dies ist ein Lern- und Portfolio-Projekt. Vor einem produktiven Einsatz müssen unter anderem Datenschutz, Zugriffskontrolle und Datensicherheit geprüft werden.
